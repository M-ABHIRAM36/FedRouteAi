# Geo V2 Model Performance Analysis Report

## Executive Summary
The Geo V2 Enhanced AdaptiveFedAvg Model integrates real-world OpenStreetMap (OSM) road network topology with a 10-feature spatial contract.

- **Evaluation Split**: 332,416 real-world samples across 8 regions
- **Global Accuracy**: 83.50% (Event Balanced Test: 63.97%, Weighted: 99.59%)
- **Macro F1 Score**: 0.6580
- **ROC AUC Macro**: 0.9785
- **Federated Payload**: 12.96 KB per round (3,240 parameters)
