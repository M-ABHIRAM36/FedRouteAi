# Abstract
Modern Intelligent Transportation Systems (ITS) heavily rely on centralized machine learning architectures that require the continuous transmission of privacy-sensitive geospatial telemetry. Although Federated Learning (FL) provides a decentralized alternative by training models directly on edge devices, deploying these models in real-world traffic environments introduces severe vulnerabilities. Specifically, edge networks frequently experience dropped sensory data and extreme Out-Of-Distribution (OOD) inputs, which can trigger mathematical saturation within batch normalization layers. To address this, we introduce FedRouteAI, an end-to-end framework integrating an `AdaptiveFedAvg` algorithm with a resilient inference pipeline. The architecture leverages a historical memory module to normalize live vehicular telemetry against localized, time-synchronized baselines. When real-time features drop out, the inference engine relies on deterministic zero-imputation and dynamic out-of-distribution warnings to preserve reliability. Experimental evaluations on a multi-class synthetic geospatial dataset demonstrate that the framework successfully identifies eight distinct traffic anomalies. Furthermore, ablation studies confirm that the adaptive aggregation mechanism achieves high-fidelity convergence (82.2% accuracy) comparable to standard federated averaging, while enabling dynamic client weighting to accommodate heterogeneous edge environments.

# Keywords
Federated Learning, Intelligent Transportation Systems, Out-Of-Distribution Detection, Edge Computing, Traffic Anomaly Classification, Adaptive Aggregation.
