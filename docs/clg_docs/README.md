# FedRouteAI Major Project Documentation

This directory contains the first editable college-report draft for the
FedRouteAI B.Tech Major Project.

- `report/FedRouteAI_Major_Project_Report.docx` is the editable report.
- `report/build_report.py` is the reproducible DOCX source generator.
- Figure spaces are deliberately placeholders. Final figures are not included
  in this pass and should be inserted only after the report numbering and text
  are reviewed.

The formatting reference was `docs/docs1.01/team_19_mini_project for reference.docx`.
The IEEE materials under `docs/docs1.01/` were not used as the report-format
reference.
