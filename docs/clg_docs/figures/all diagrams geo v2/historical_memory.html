Zone Baseline Retrieval & Normalization

Every classification depends on comparing a vehicle's current telemetry against what's normal for its specific zone and time window — a highway at rush hour and a residential street at midnight have completely different baselines. This module is what makes the rest of the pipeline privacy-preserving: it stores aggregated statistics, never individual vehicle records.

Formulas

Speed ratio
$$v_{ratio} = \dfrac{v_{current}}{\bar{v}_{zone,\,t}}$$
Ratio > 1 means faster than this zone's own historical norm for this time window — not faster than some global average, which would be meaningless comparing a highway to a residential street.
Density ratio
$$d_{ratio} = \dfrac{d_{current}}{\bar{d}_{zone,\,t}}$$
Same normalization logic applied to local traffic density.

Why This Step Exists

Classifying absolute speed or density would force the model to separately learn what "normal" looks like for every road type — a hopeless generalization problem with limited data. By normalizing to each zone's own time-windowed baseline first, the exact same downstream MLP can reason about a highway and a residential lane using the same feature scale. This is also the privacy-relevant step: the database stores aggregated zone statistics, never a queryable history tied to an individual vehicle.
