Why the Payload Is So Small

EventClassifierMLP has 3,240 trainable parameters — at 32-bit floats, that's exactly 12.96 KB per direction. This is small enough that communication cost is genuinely a non-issue at this model scale; techniques like delta/sparse updates (sometimes proposed for FL) would be solving a problem this system doesn't have.

What This Diagram Deliberately Doesn't Show

Client dropout, delayed/asynchronous arrival, and partial-round participation — because, as flagged in the earlier design review, the current 8-client simulation reports synchronously every round. If freshness/reliability terms are claimed to handle unreliable clients, an actual dropout experiment (and a corresponding diagram variant) is needed to back that claim.
