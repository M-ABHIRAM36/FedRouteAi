Why Ratios, Not Raw Values

A model trained on absolute speed would need to separately learn "40 km/h is slow" for a highway and "40 km/h is fast" for a school zone. Ratio features collapse this into one shared scale: 0.5 always means "half of this specific location's own normal," regardless of road type — this is what lets one small MLP generalize across every zone in the network with only 3,240 parameters.

Honest Framing Recommendation

Section III-C's prose currently implies the four zero-filled features represent dynamically detected missing data from a degraded sensor. As implemented, the single-prediction endpoint simply never collects them — every request gets the same zero-fill, whether or not anything is actually unavailable. Either reword the paper to describe this precisely, or extend the endpoint to accept these fields when a caller has them, so the zero-fill becomes a genuine fallback rather than a fixed constant.
