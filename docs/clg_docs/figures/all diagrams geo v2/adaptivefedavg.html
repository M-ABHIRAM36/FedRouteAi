Why These Three Factors

  • Quality answers "did this update actually learn something" — floored so one noisy round never zeroes a client out entirely.
  • Rarity directly counters the confirmed non-IID problem: without it, a client that happens to see a rare event this round gets diluted exactly when its signal matters most.
  • Reliability is a gate, not a second continuous quality multiplier — it answers "has this client been chronically bad," a different question from this round's quality score.
