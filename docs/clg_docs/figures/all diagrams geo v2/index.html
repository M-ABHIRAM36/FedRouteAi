Using These Files

For the IEEE Paper

  • Open any figure page, click Export SVG — downloads a standalone, self-contained .svg (styles are embedded, no external stylesheet needed).
  • Convert for LaTeX: inkscape figure.svg --export-type=pdf, then \includegraphics as usual — vector, crisp at any print size.
  • Default theme is light/print-safe by design — don't toggle dark mode before exporting for print.
