What "Deployment-Aware" Actually Means Here

The OOD check is real and correctly implemented — a genuinely useful reliability signal. What it is not, as currently built: a system that detects which specific fields are missing from a live sensor and reacts accordingly. That would require the /predict endpoint to accept partial input and detect absence — a real, buildable extension, but a different (larger) claim than what Figure 3's fixed zero-fill currently supports.
