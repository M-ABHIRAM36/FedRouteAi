FedRouteAI End-to-End Architecture

Everything left of the privacy boundary — telemetry collection, historical normalization, feature engineering, and edge inference — runs per regional client using only that client's own data. Only trained model weights (12.96 KB) cross the boundary to the central server. Raw GPS, feature vectors, and predictions never leave the client.

What Actually Crosses the Boundary

  • Upload (12.96 KB): this round's trained local weights w_k, validation loss L_k, and sample count n_k — never raw GPS, never the 10-D feature vector, never a prediction.
  • Download (12.96 KB): the aggregated global model's weights only.
  • Never transmitted: raw telemetry, historical baselines, engineered features, or individual predictions — all four stay inside the regional client's own boundary.

An Honest Note on "Edge"

In this simulation, "edge inference" is served by the /predict FastAPI endpoint rather than running on physical roadside hardware — the architecture and the privacy boundary are real, but the physical edge deployment described in the Limitations section is future work, not what was benchmarked. State this precisely in Section III-A rather than implying physical edge nodes were used.
